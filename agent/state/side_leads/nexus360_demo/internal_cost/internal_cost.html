4. Claude plan (USD 100) and the page + video

  • Yes, it uses the limit, but only once. Designing the Nexus360 page, video script and QA is about 1.5 to 3M tokens one time (API-equivalent about Rs 200 to 400). Assumption
  • Each lead's page and video use no AI tokens: they are made by scripts (build_site_pages.py, render_master.py). Render is local (40 s to 5 min).
  • Hosting on our VPS costs no tokens; only the deploy session does (about 20 to 50k tokens). The server is already paid.
  • Research is the big one: 300k tokens x 100 builders = 30M tokens a month, too much for a plan with opaque limits (we hit the limit today). Client work should run on pay-per-use API (Rs 76 a builder).
